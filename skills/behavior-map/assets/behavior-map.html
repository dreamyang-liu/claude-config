Behaviors


Each behavior is a goal of a real actor. Select one to see where its steps are handled.







Allocation


Read from top to bottom. The first column is the actor: the trigger at the top, the outcome
  at the bottom, and each step that the actor does. Each other column is a component at the current zoom. Each box is one or
  more steps in order. Each arrow hands control to the next step, labeled with the call or the message.
  Click a column head with + to show its subcomponents. Click a dashed group head to hide them.







Components


Each component, with the number of steps that it or its subcomponents handle. Click a name to zoom to it.





Trace matrix


The step numbers that each component handles, at the current zoom. A red column has no step.
